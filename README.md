# Zisto — Airbnb First Impression Demo

Static HTML/CSS/JS demo based on the approved Figma Smart Link for **Mary’s Room**.

- Responsive mobile-first layout matching the Figma screen
- Exact exported Zisto logo and icon SVGs
- Functional EN / GR toggle
- Interactive House Rules, House Manual, Transfer Details, Contact Host and Review bottom sheets
- Lightweight local demo event tracking via `window.zistoDemoEvents`
- No framework, build step, database or backend required

Demo credentials and actions are placeholders and should be replaced before a real client deployment.
